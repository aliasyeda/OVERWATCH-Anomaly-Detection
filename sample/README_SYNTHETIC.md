# ⚠️ Synthetic Test Data — Not Real Traffic

`suspicious_logs.log` in this folder is **synthetically generated**, not
part of the real NASA-HTTP dataset. It exists purely to demonstrate that
the trained detection pipeline actually fires on clearly-anomalous behavior,
since the real August 1995 NASA access log contains essentially no
malicious traffic (it predates most modern web attack patterns and this
is ordinary public-web browsing traffic).

It contains, interleaved with normal-looking background requests:
- A fast automated scan of common admin/CGI paths from one IP (404s, sub-second spacing)
- High-frequency repeated POSTs to a login endpoint from one IP (brute-force-style pattern)
- A handful of requests with SQL-injection / path-traversal / XSS-style payloads in the query string

Generated by a fixed random seed in a short script (see project history) —
timestamps, IPs, and payloads are fabricated for demonstration only.
